# Acceptance 06: Risk Tier

Expected outcome:

- The answer names the changed surfaces before choosing a tier.
- The tier is justified with blast radius, reversibility, and verifiability.
- Currency math, API shape, architecture, CI, or visible totals land in Review.
- Local, reversible, well-tested edits can land in Own.
- Broad, credentialed, release-sensitive, or hard-to-prove changes land in
  Delegate.
- `exercises/06/artifacts/` mirrors the risk matrix and triage skill added by
  this lesson.

Verification:

```bash
npm run check
```
