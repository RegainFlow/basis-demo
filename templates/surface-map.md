# Surface Map

Use the smallest durable surface that fits the correction.

| Surface    | Use When                                      |
| ---------- | --------------------------------------------- |
| Prompt     | One-off task instruction                      |
| AGENTS.md  | Repo or package convention                    |
| Skill      | Repeated workflow with steps and output shape |
| Template   | Copyable starter artifact                     |
| CI gate    | Mechanical check that should block merge      |
| Automation | Scheduled or recurring report                 |
